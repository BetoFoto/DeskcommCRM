secao: corrigido
titulo: Reabrir uma tarefa cancelada a devolve para Pendente, não para Concluída
---

Na tela de Tarefas, a caixa de uma tarefa cancelada já aparecia marcada e com o rótulo "Reabrir a tarefa", mas o clique gravava a tarefa como CONCLUÍDA em vez de reabri-la. Se a tarefa estiver ligada a um negócio, a linha do tempo desse negócio também ganhava "Tarefa concluída" de um trabalho que ninguém fez. Agora o clique devolve a tarefa para Pendente, como já acontecia com uma concluída, e nenhuma linha de tarefa concluída é registrada no processo. Não é preciso fazer nada na instalação.

Contribuição de @webtecnica (#2557), a partir da issue #2549 de @hudson-souza-mkt.
